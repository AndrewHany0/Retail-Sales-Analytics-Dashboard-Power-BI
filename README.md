📊 Retail Sales Analytics Dashboard | Power BI
📌 Project Overview

This project presents a comprehensive Retail Sales Analytics Dashboard built using Power BI to analyze business performance across sales, orders, and customers.

The dashboard was developed using the Superstore dataset and provides actionable insights to support data-driven decision-making.

🎯 Business Objectives
Analyze overall sales performance.
Monitor order trends and operational metrics.
Understand customer behavior and segmentation.
Identify top-performing regions, cities, and product categories.
Support strategic business decisions through interactive reporting.
📊 Dashboard Structure

1. Executive Dashboard

Provides a high-level overview of key business KPIs including:
Total Sales
Total Orders
Total Customers
Sales Trends
Regional Performance

2. Sales Dashboard

Analyzes:
Sales by Category
Sales by Region
Sales by City
Sales by Segment
Sales by Shipping Mode

3. Orders Dashboard

Analyzes:
Order Distribution
Order Trends Over Time
Shipping Performance
Operational Metrics

4. Customer Dashboard

Analyzes:
Customer Segments
Customer Purchasing Behavior
Top Customers
Customer Distribution
